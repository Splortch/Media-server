# Shared API contract

`openapi-v1.json` is exported from the actual backend using the fixture integration test. `src/generated.ts` is generated by `npm run generate`; do not hand-edit it. `src/client.ts` provides reusable, bounded-response-aware client operations and a serialized revision writer over an injectable transport. The web frontend keeps its existing cookie transport; the Windows client supplies a restricted Rust IPC transport.

See [the regeneration commands and authentication contract](../../docs/clients/API.md). CI regenerates both files and rejects drift. Rust transport logic is not generated, because its security boundary includes cookie isolation, a strict URL/operation allowlist and streaming rather than duplicating raw HTTP methods in JavaScript. Android/Swift model generation belongs to those implementation PRs.
